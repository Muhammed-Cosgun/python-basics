# 🐍 Python Temelleri ve Eğitim Projelerim

Bu depo, Python programlama dilini öğrenme sürecimde yazdığım temel kodları, egzersizleri ve konu anlatımlı küçük projeleri içermektedir.

## 📁 Depo İçeriği
* **Değişkenler ve Veri Yapıları:** Python veri tipleri ve temel manipülasyonlar.
* **Koşullu Durumlar ve Döngüler:** Karar yapıları (if-else) ve döngü mekanizmaları.
* **Fonksiyonlar & Modüller:** Kodun yeniden kullanılabilirliği ve kütüphane kullanımları.
* **OOP (Nesne Yönelimli Programlama):** Sınıflar, nesneler ve kalıtım yapıları.
* **Hata Yönetimi ve Dosya İşlemleri:** Try-except blokları ve veri saklama yöntemleri.

## 🚀 Nasıl Çalıştırılır?
Klasör içerisindeki herhangi bir `.py` dosyasını bilgisayarınıza indirip terminal üzerinden şu komutla çalıştırabilirsiniz:
```bash
python dosya_adi.py
```
